# Política de atualizações do CURIÓ

Desde 2026-10-04 UTC: publicar a cada **3 updates** funcionais. Correções pertencentes ao mesmo update não contam como novos itens.

Toda mudança compartilhada deve ser aplicada e validada no site e na base Android. Recursos específicos de plataforma devem ter equivalentes apropriados ou limitação registrada. O deploy web não atualiza APKs instalados: gerar e instalar o APK correspondente.

Lote atual: destaque com recorte, base Android, deslize contínuo compartilhado, login compacto com visibilidade temporária da senha. Publicação extraordinária solicitada pelo usuário. Após publicação confirmada: contador 0/3.

Amazon e demais afiliados ainda não foram integrados; IDs e exemplos coletados não equivalem a implementação.
